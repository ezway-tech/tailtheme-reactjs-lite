# TailTheme React Lite — Agent Guide

## Scope

Free-scope MIT admin template generated from `tailtheme-reactjs-full`
(`npm run sync:lite` / preset `lite`). Matches the historic TailTheme Free page
set and shell — not the `minimal` starter export.

## Rules

- Prefer PRs against **Full** for shared UI / tokens / patterns.
- Do not add purchase CTAs, Pro teasers, or locked navigation.
- Keep Free-scope pages (dashboards, SaaS, Project, UI docs subset).

## Commands

1. `npm run typecheck`
2. `npm run lint`
3. `npm run test:run`
4. `npm run format:check`
5. `npm run build`
